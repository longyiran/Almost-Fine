# Almost Fine

Explore the aftermath of an accident as a cat. Collect illustrated clues, connect them in your notebook, then return to the scene before the accident and possess an everyday object to help someone.

**[Download the latest playable demo and English play guide](https://github.com/longyiran/Almost-Fine/releases/latest)**

| Platform | How to play |
| --- | --- |
| macOS · Apple Silicon or Intel | Extract the macOS ZIP and open **Almost Fine.app**. |
| Windows · x64 | Extract the entire Windows ZIP and open **AlmostFine.exe**. Keep **AlmostFine.pck** beside it. |

Both downloads run on their own. The illustrated PDF on the release page covers system requirements, first launch, controls, and a route through each case.

- **Case 1 · The Last Coffee** — Reconstruct one accident in the apartment. A sticker you create can become evidence for the next deduction.
- **Case 2 · CHEERS!** — Investigate four people at a party. For a short first session, follow the fallen cleaner, connect the two cleaning products, and try the dusk rescue.
